Политика конфиденциальности

Действует с 1 ноября 2026 года

Настоящая Политика конфиденциальности описывает обработку данных в мобильном приложении «Мира» (далее — «Приложение»), созданном в рамках проекта InclusiveTech («Инклюзивные технологии»). Приложение помогает общению глухих, слабослышащих и слышащих людей посредством распознавания жестового языка и преобразования речи в текст.

1. Оператор и контакты

Оператор персональных данных: Рассудительнова Екатерина Сергеевна. По вопросам обработки данных и для запросов об их удалении можно написать на khurtovaekaterina@gmail.com.

2. Обработка и хранение видео

Когда пользователь включает распознавание жестового языка, Приложение получает видео с камеры и передаёт его на сервер для распознавания и преобразования жестов в текст. Хранение видеозаписей осуществляется исключительно для технического обеспечения обработки и работы Приложения. Пользователи не имеют доступа к сохранённым видеозаписям и не могут просматривать их через Приложение.

Срок хранения видео — не более 7 календарных дней с момента получения сервером. По истечении этого срока записи автоматически удаляются. Резервные копии видеозаписей не создаются.

Видео может содержать изображения лиц пользователя и других людей, попавших в кадр. Видео не используется для обучения моделей искусственного интеллекта, рекламы или построения рекламных профилей.

3. Голос и микрофон

Приложение может получать звук с микрофона для перевода устной речи в текст. Распознавание выполняется локально на устройстве: аудиозаписи не направляются на сервер и не сохраняются оператором.

4. Технические сведения об устройстве

Для технической совместимости и работы Приложения используются и передаются серверу минимальные сведения: производитель и модель устройства, версия Android и технические характеристики, необходимые для выполнения функций.

В Приложении не используется отдельная система аналитики и целевой сбор отчётов об ошибках. При сетевом взаимодействии серверная инфраструктура может технически обрабатывать сведения о соединении, включая IP-адрес, в объёме, необходимом для приёма и обслуживания запросов. Эти сведения не используются для рекламного профилирования.

5. Учётные записи и обращения

Приложение доступно без создания учётной записи. Для его использования не требуется предоставлять имя, номер телефона или адрес электронной почты. Если пользователь самостоятельно направляет обращение по электронной почте, содержащиеся в нём контактные данные обрабатываются для ответа и рассмотрения запроса.

6. Цели обработки и уведомление пользователя

Данные используются для распознавания жестового языка, технической обработки видеозаписей, выполнения функций Приложения и обеспечения его работоспособности.

До первой передачи видео Приложение сообщает пользователю, что видео передаётся на сервер и сохраняется до 7 дней, предоставляет ссылку на настоящую Политику и возможность отказаться от отправки. Там, где требуется согласие, оно запрашивается посредством отдельного активного действия пользователя. Если цели или условия обработки существенно изменятся, предоставляется обновлённая информация и при необходимости запрашивается новое согласие.

7. Сервер, доступ и защита

Для обработки и хранения видеозаписей используется серверная инфраструктура Приложения, расположенная на территории Российской Федерации. Передача видео на сервер осуществляется по защищённому соединению HTTPS; видеозаписи находятся в зашифрованном хранилище. Доступ к сохранённым записям ограничен уполномоченными разработчиками, которым он необходим для обслуживания Приложения.

Для работы Приложения может использоваться инфраструктура технических подрядчиков, обрабатывающих данные по поручению оператора в пределах, необходимых для предоставления услуг. Сторонние рекламные и аналитические SDK не используются. Данные не передаются третьим лицам для самостоятельного использования в рекламных целях. Сведения об обработчиках предоставляются в случаях и порядке, предусмотренных применимым законодательством.

8. Удаление данных и права пользователя

Видео автоматически удаляется не позднее 7 календарных дней после поступления на сервер. Пользователь может запросить досрочное удаление конкретной видеозаписи, направив письмо на khurtovaekaterina@gmail.com. Уполномоченный разработчик рассматривает запрос и выполняет удаление вручную после установления того, к какой записи относится обращение, и проверки правомерности удаления.

По указанному адресу также можно запросить сведения об обработке данных, их уточнение, блокирование, удаление и сообщить об отзыве согласия. Запросы рассматриваются в порядке и сроки, установленные применимым законодательством. Необходимые для обработки обращения сведения используются только для этой цели и в соответствии с законными сроками хранения.

9. Изменения Политики

При изменении функций Приложения или способов обработки данных настоящая Политика обновляется. Актуальная редакция размещается по адресу https://mira.inclusivetech.ru/privacy/.
